# Fonts

Self-hosted so the demo works offline and screenshots are reproducible. All three families are licensed under the
SIL Open Font License 1.1 (see the `LICENSE-*.txt` files next to them).

| Family | Weights | Source |
|---|---|---|
| Barlow Condensed | 600, 700 | `@fontsource/barlow-condensed@5.2.6`, latin subset |
| IBM Plex Sans | 400, 500, 600 | `@fontsource/ibm-plex-sans@5.2.6`, latin subset |
| IBM Plex Mono | 400, 500 | `@fontsource/ibm-plex-mono@5.2.6`, latin subset |

The latin subset covers Spanish (á é í ó ú ü ñ ¿ ¡).
